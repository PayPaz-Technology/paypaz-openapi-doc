On-Ramp 法币入金业务接口 DRAFT

以下业务接口均需通过签名认证（与现有充值 / 提币 OpenAPI 相同）。 本能力用于商户终端用户以法币（银行转账、信用卡/借记卡、Apple Pay、Google Pay）购买加密资产，并入账至 Paypaz 账户。

文档状态：接口路径与字段为商户对接需求草案，上线前以正式发布版本为准。 鉴权、域名、签名算法请参阅 认证 API 文档。

环境域名（同现网 OpenAPI）

环境说明域名
预发布环境 测试联调 https://open-api.paypaz.dev
生产环境 正式上线 https://open-api.paypaz.com

公共请求头

Header说明

对接流程说明

  1. 确保子用户已存在：使用商户侧 clientSubUserId（与现有充值/提币一致）。On-Ramp 强制要求子用户。
  2. 调用 获取交易对 / 获取支付方式 / 获取国家列表，动态展示支持的法币、加密货币与支付通道。
  3. 调用 询价，向用户展示到账数量与费用明细。
  4. 调用 查询 KYC 状态；若未通过，引导用户完成 KYC（托管页内置流程，或自建页调用 KYC SDK URL）。
  5. 调用 创建 On-Ramp 订单。
    • 托管页模式：使用返回的 checkOutUrl 引导用户完成支付与 KYC。
    • 自建页模式：商户自研页面；银行转账调 收款账户；卡 / Apple Pay / Google Pay 调 SDK 签名 后使用 Paypaz 下发的支付组件完成支付。
  6. 用户完成支付后，Paypaz 在链上到账确认后入账，并向商户发送 Webhook。
  7. 商户也可轮询 订单详情 / 分页查询 获取结果。
入账说明：订单状态变为 completed 表示加密资产已入账至该子用户 Paypaz 余额。 中间态（待付款、处理中）不代表已到账。

两种接入模式

模式说明商户工作量适用场景
托管页模式 创建订单后跳转 checkOutUrl，用户在 Paypaz 托管页完成选支付方式、KYC、付款 低：建单 + 接 Webhook 快速上线，体验统一
自建页模式 商户自研 UI，调用 OpenAPI 完成询价/建单/KYC/收款信息/支付 SDK 签名 高：需实现完整前端与 SDK 集成 强品牌定制

两种模式共用同一套订单与 Webhook，可按订单选择；创建时可忽略或使用 checkOutUrl。

订单状态

status含义说明
pending已创建 / 待 KYC订单已生成，可能需完成身份认证
awaiting_payment待支付等待银行汇款或卡/钱包支付
processing处理中法币已受理，等待兑币与链上到账
verification_required需补充验证合规要求补充材料（EDD/RFI），请提示用户查收邮件/完成验证
completed已完成链上确认完成，余额已入账
failed失败支付或交易失败
expired已过期超过订单有效期未完成支付

支付方式枚举 paymentMethod

值说明
bank银行转账（含各地本地转账 / 电汇等，以 deposit-methods 返回为准）
card信用卡 / 借记卡
apple_payApple Pay
google_payGoogle Pay

1. GET 获取交易对 签名

获取 On-Ramp 支持的交易对、限额与精度。请动态拉取，勿硬编码币种。

GET/t-api/openapi/v1/op/openapi/onramp/pairs

请求参数

无（或按正式版支持可选过滤参数）

返回示例

200 Response{
  "code": 200,
  "msg": "success",
  "data": [
    {
      "pair": "USDTJPY",
      "fiatCurrency": "JPY",
      "tokenId": "USDT",
      "minSize": "2000",
      "maxSize": "1560000",
      "sizePrecision": 0,
      "quantityPrecision": 2
    }
  ]
}

OnRampPairVO 属性

名称类型必选说明
pairstringfalse交易对，如 USDTJPY
fiatCurrencystringfalse法币代码
tokenIdstringfalse加密货币代码
minSize / maxSizestringfalse法币金额限额
sizePrecisionintegerfalse法币精度
quantityPrecisionintegerfalse加密货币精度

4. POST 询价 签名

根据法币金额获取可购买的加密货币数量及费用明细。银行与卡报价可能不同，请传 paymentMethod 或 type。

POST/t-api/openapi/v1/op/openapi/onramp/quote

Body 请求参数

{
  "clientSubUserId": "csub_abc123",
  "pair": "USDTJPY",
  "fiatAmount": "15600",
  "paymentMethod": "bank",
  "tokenId": "USDT",
  "chainId": "TRON"

5. POST 创建 On-Ramp 订单 签名

为指定子用户创建法币买币订单。托管页模式请使用返回的 checkOutUrl。

POST/t-api/openapi/v1/op/openapi/onramp/orders

特殊说明

  • clientOrderNo 为商户侧唯一键，用于幂等；重复提交同一单号将返回原订单。
  • 必须传入 clientSubUserId（或正式版支持的 subUid）。
  • 预发布环境建议使用 tokenId=USDT、chainId=TRON 进行联调。

Body 请求参数

{
  "clientSubUserId": "csub_abc123",
  "clientOrderNo": "ONRAMP-20260723-0001",
  "pair": "USDTJPY",
  "fiatCurrency": "JPY",
  "fiatAmount": "15600",
  "tokenId": "USDT",
  "chainId": "TRON",
  "paymentMethod": "bank",
  "returnUrl": "https://merchant.example.com/onramp/callback",
  "partnerCode": "P01"
}

8. GET 获取银行收款账户 签名

自建页 + 银行转账时，展示平台收款账户信息。用户汇款时必须填写正确的 reference（一般为订单 orderNo）。

GET/t-api/openapi/v1/op/openapi/onramp/deposit-account

请求参数

名称位置类型必选说明
clientSubUserIdquerystringtrue客户子用户唯一标识
fiatCurrencyquerystringtrue法币
orderNoquerystringfalse关联订单号；建议传入以便返回对应 reference

返回示例

200 Response{
  "code": 200,
  "msg": "success",
  "data": {
    "fiatCurrency": "JPY",
    "bankName": "三菱UFJ銀行",
    "branchName": "大手町支店",
    "accountType": "普通",

11. POST 获取支付 SDK 签名 签名

自建页使用卡 / Apple Pay / Google Pay 时，需先向本接口申请授权签名包，再在前端初始化支付 SDK（由 Paypaz 提供接入说明与脚本地址）。 商户服务端不得将 API Secret 暴露给前端；仅将本接口返回的短期签名字段交给前端。

Body 请求参数

  "phone": "+819012345678"
}

返回示例

200 Response{
  "code": 200,
  "msg": "success",
  "data": {
    "timestamp": "1721700000",
    "signature": "xxxxxx",
    "appId": "APP-ID",
    "appKey": "APP-KEY",
    "appUid": "123456_789012",

Webhook 通知

商户需配置回调地址并订阅 On-Ramp 相关事件。签名验证方式与现有 Webhook 相同，详见 webhook 说明。

错误码（草案）

错误码说明
500106001On-Ramp 订单号已存在（非幂等命中场景的冲突）
500106002法币金额不合法或超出限额
500106003不支持的支付方式或法币
500106004KYC 未通过，无法下单/支付
500106005报价已过期，请重新询价
500106006子用户不存在或 clientSubUserId 无效
500106007地区不可用（合规限制）
500106008需要补充验证（EDD/RFI）
500106009API Key 未开通 onramp 权限

最终错误码以正式发布文档为准；通用鉴权错误码同 认证 API 文档。

注意事项

  • On-Ramp 与链上充值（deposit / pay-in）是不同产品：前者为法币买币，后者为链上转入。
  • 必须以 completed / transaction.onramp.completed 作为用户到账依据，勿以「已提交汇款」或支付 SDK 的 pending 作为最终成功。
  • 银行转账请强调：金额一致、使用本人账户、备注填写 orderNo。
  • 卡 / Apple Pay / Google Pay：PCI 相关字段不得经过商户服务器，仅通过 Paypaz 提供的前端 SDK 采集。
  • 请始终传递终端用户真实 IP（建议 Header X-User-Ip），否则可能触发风控拒绝。
  • 支持的法币、支付方式、国家以接口实时返回为准，请勿写死。
  • 费率包含在询价结果的 commission / fee 字段中，下单前请向用户清晰展示。
